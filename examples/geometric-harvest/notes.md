# Geometric Harvest

## Summary

Geometric Harvest is a public example for **Clean Vector Reconstruction**.

It demonstrates the `geometric-flat` reconstruction workflow on a user-created original flat illustration.

The goal is not pixel-perfect tracing. The target is an **Illustrator-ready reconstruction** with:

* clean semantic SVG structure
* editable vector objects
* no embedded raster
* correct major composition and object relationships
* limited remaining work for local Illustrator refinement

## Files

* `reference/reference.png` — original raster reference
* `output/layered.svg` — layered editable SVG
* `output/plain.svg` — plain compatibility SVG
* `output/preview.png` — Adobe Illustrator-exported preview of the final layered SVG

## Reconstruction profile

* Mode: `geometric-flat`
* Reference type: user-created original illustration
* Intended editor: Adobe Illustrator
* Public example status: approved

## Why this example is included

This example demonstrates:

* clean color-block reconstruction
* semantic vector rebuilding
* Illustrator-oriented editability
* native SVG gradients
* avoidance of embedded raster imagery
* avoidance of fragment-heavy tracing

The published package intentionally excludes internal diagnostics, correction history, local scripts, and private review materials.
